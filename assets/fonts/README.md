# Písma

**Barlow Condensed** (SIL Open Font License, `BarlowCondensed-OFL.txt`) je jediné písmo
obrázkov aj nadpisov stránky. Je uložené priamo tu, takže nezávisí od Google Fonts:

| súbor | použitie |
|---|---|
| `barlow-condensed-semibold.ttf` | bežný text (váha 400 v canvase) |
| `barlow-condensed-extrabold.ttf` | tučný text (váha 700) |
| `barlow-condensed-semibolditalic.ttf` | kurzíva |
| `barlow-condensed-blackitalic.ttf` | tučná kurzíva – nadpisy obrázkov |

Pôvodné komerčné písmo **Biome W04 Regular** v repozitári nie je. Ak ho máte s licenciou,
môžete ho nahrať ako `biome-w04-regular.otf` – v editore sa potom dá vybrať, a potrebujú ho
iba staré serverové generátory `generate-match-*`.
