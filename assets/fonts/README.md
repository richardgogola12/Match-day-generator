# Písma

Pôvodné písmo šablón **Biome W04 Regular** je komerčné, preto nie je súčasťou repozitára.
Ak máte licenciu, nahrajte ho na server ako:

    assets/fonts/biome-w04-regular.otf

Bez neho editor a generátor použijú náhradné písmo (Google Fonts alebo systémové),
pôvodné serverové generátory `generate-match-*` však písmo potrebujú.
